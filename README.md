# PIntel Market Dashboard

A real-time market intelligence dashboard tracking PETRONAS news and announcements, powered by AI-generated daily insights.

**Live:** https://pintelmarket.netlify.app/

---

## What It Does

PIntel aggregates daily PETRONAS-related news from a curated feed, categorises each article automatically, and uses a large language model (Groq `llama-3.3-70b-versatile`) to produce a structured market intelligence briefing every morning. The result is a single-page dashboard where analysts can quickly scan sentiment, sector activity, and key signals without reading dozens of articles manually.

---

## Features

| Feature | Detail |
|---|---|
| **Live data feed** | CSV updated daily at 08:00 MYT via GitHub Actions |
| **Auto-categorisation** | Rules-based: Energy & Gas, Chemicals, Renewables, Sponsorship, Financial, International |
| **AI daily briefing** | Overall market score, 5 signal cards, sector trends, recommendation — generated once per day and cached |
| **Trend charts** | 30-day publication volume (area), category breakdown (donut), topic frequency (bar), sector radar |
| **Topic tracking** | Keyword extraction surfacing the most-discussed themes |
| **Article feed** | Full feed with category filter + keyword search |
| **Mobile-first layout** | Sidebar navigation on desktop, bottom tab bar on mobile with safe-area support |
| **Glassmorphism UI** | Dark theme with PETRONAS teal (#00a19c) accent, framer-motion animations, shimmer loading states |


The CSV is refreshed every day at 00:00 UTC (08:00 MYT) by a scheduled GitHub Actions workflow in the `booluckgmie/sharecode` repository.

Expected columns: `title`, `published`, `link`, `source`

## AI Insights

Insights are generated by calling the Groq API with a structured prompt that summarises the latest articles. The response is cached in `localStorage` and reused for the rest of the calendar day, keeping API usage minimal.

The JSON schema returned by the model:

```json
{
  "overall_score": 72,
  "overall_sentiment": "positive",
  "summary": "...",
  "signals": [
    { "title": "...", "detail": "...", "sentiment": "positive", "score": 80 }
  ],
  "sector_trends": { "Energy & Gas": "rising", "Renewables": "stable" },
  "recommendation": "...",
  "model": "llama-3.3-70b-versatile",
  "generated_at": "2025-01-01T08:00:00.000Z"
}
```

### Setting the API Key

The Groq API key is **never committed to source control**. Set it as a Netlify environment variable:

1. Go to Netlify → **pintelmarket** → Site settings → **Environment variables**
2. Add variable: `REACT_APP_GROQ_API_KEY` = `<your Groq API key>`
3. Trigger a redeploy

Without the key the dashboard still works — it shows a fallback insight panel instead of a live AI briefing.

## Local Development

```bash
# 1. Clone
git clone https://github.com/booluckgmie/pintel-dashboard.git
cd pintel-dashboard

# 2. Install dependencies (requires Node 18)
npm install

# 3. Add your Groq key
echo "REACT_APP_GROQ_API_KEY=gsk_..." >> .env

# 4. Start dev server
npm start
```

The app runs at `http://localhost:3000`.

## Deployment

The project is connected to Netlify via the `netlify.toml` config at the repo root. Every push to the main branch triggers an automatic build and deploy.

```toml
[build]
  command = "npm run build"
  publish = "build"

[build.environment]
  NODE_VERSION = "18"
```
